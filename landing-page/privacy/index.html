Privacy Policy

Last updated: February 2026

sys-monitor is an open-source, offline terminal application. This policy explains what data the application does and does not collect.

No data collection

sys-monitor does not collect, transmit, or store any personal data. The application runs entirely on your local machine and does not make any network requests during normal operation.

System data

sys-monitor reads system metrics (CPU usage, memory usage, process list, hostname, and uptime) from your operating system's APIs. This data is used solely to render the terminal interface and is never transmitted to any external server.

Self-update

When you run sys-monitor upgrade, the application makes an HTTPS request to the GitHub API to check for new releases and downloads the updated binary. This is the only network activity performed by sys-monitor, and it only happens when you explicitly request an update.

Install script

The install script fetches the latest binary from GitHub Releases. This download is subject to GitHub's own privacy policy. No additional data is collected by the install script.

This website

This website is a static site. It does not use cookies, analytics, tracking pixels, or any third-party scripts. No personal information is collected through this website.

Third-party services

The only external resources loaded by this website are fonts from Google Fonts. Google Fonts is subject to Google's privacy policy.

Open source

The full source code of sys-monitor is available on GitHub. You can audit the code to verify these claims.

Contact

For questions about this policy, you can reach the project maintainer at youssef.tn.
